\cvsection{Case Studies}

\cvevent{PHP-FPM → Laravel Octane Migration}{EdTech Platform}{}{}
{\small\textbf{Challenge:}} Slow responses (800ms avg), poor concurrency, high CPU usage with PHP-FPM.

{\small\textbf{Solution:}} Migrated to Laravel Octane + Swoole for async I/O and in-memory caching. Used coroutines, process-level caching, and DB connection pooling.

{\small\textbf{Impact:}} Response times: \textbf{800ms → 40–60ms}, \textbf{5×} concurrency, \textbf{30–40\%} lower infrastructure costs

\bigskip

\cvevent{Monolith → Microservices Migration}{EdTech \& SaaS Platforms}{}{}
{\small\textbf{Challenge:}} Monolith caused scaling issues, slow deployments, and delayed feature releases.

{\small\textbf{Solution:}} Gradually migrated to microservices on Kubernetes while keeping the old system running, with full observability.

{\small\textbf{Impact:}} Better fault isolation, independent deployments, service-level scaling

\bigskip

\cvevent{Real-time Observability Platform}{Clients}{}{}

{\small\textbf{Solution:}} Built end-to-end observability with tracing, centralized logging, metrics, and Grafana dashboards.
